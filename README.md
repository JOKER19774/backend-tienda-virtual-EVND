# Tienda Virtual API

API REST para administrar un carrito de compras.

## Instalación

```bash
npm install
```

## Dependencias

- express
- body-parser
- morgan

## Ejecución

Crea un archivo `index.js` con tu servidor y luego:

```bash
node index.js
```

## Estructura sugerida

- `index.js`: punto de entrada del servidor.
- `routes/`: rutas de productos y carrito.
- `controllers/`: lógica de negocio.

## Notas

- Asegúrate de tener `.gitignore` con `node_modules/` para no subir dependencias.
